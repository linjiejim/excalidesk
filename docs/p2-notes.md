## 修掉的问题

1. **打开文件就写一次盘。** 原因不是文字重新测量（0.18.1 的 `Fonts.onLoaded` 只清缓存、不改版本号），而是 **appState 规整**：Excalidraw 挂载时会补上 `gridStep`、`gridModeEnabled` 等默认值，和从原始文件取的基线对不上。修法：基线也先过一遍 `restoreAppState`。另外留了一个兜底：挂载后 4 秒内、用户还没动过画布时，Excalidraw 自己引起的变化不算改动。
2. **每次保存都重扫目录树。** 自己保存引起的 FSEvents 事件（磁盘状态和最后一次写入一致）在 Rust 侧过滤掉，不再通知前端。

## 一个被数据否掉的设计：窗口毛玻璃

最初按「透明标签栏」做了窗口透明 + 系统侧边栏毛玻璃（`NSVisualEffectView`）。基准实测（同一张 3000 元素的大图，120Hz）：

| 窗口样式 | 100% 平移 | 全图可见平移 | 30% 平移 | 缩放 | 手绘 |
|---|---|---|---|---|---|
| 普通窗口 | 119.8 | 12.6 | 47.1 | 38.4 | 119.2 |
| 透明 + 毛玻璃 | 111.9 | 8.3 | **24.4** | **23.5** | 120.1 |
| 透明标题栏（最终方案） | 120.1 | 14.4 | 50.2 | 38.6 | 118.7 |

透明 WKWebView 每帧都要带 alpha 合成，缩放和中等缩放平移掉一半。所以最终只保留透明标题栏，标签栏用和侧边栏一样的底色连成一片。

## 打包

`npm run release`：发布构建去掉基准和自测用的 5.5MB 测试场景，用 `hdiutil` 直接打 DMG（不驱动 Finder，不需要自动化权限）。v0.2.0 的 DMG 约 19.6MB，ad-hoc 签名，只能在本机或手动放行后运行；要分发给别人需要 Developer ID 签名和公证。

## 验证

- Rust 单元测试 8 个（新增：历史快照往返与清理、重命名时同步路径）。
- 端到端自测 18 步全部通过（`npm run selftest`）。新增：打开文件不写盘（并确认规整确实发生了）、用户编辑后连同规整结果一起保存、重命名打开中的文件、创建副本、新建文件夹并在其中新建图、历史版本自动留档与恢复、文件被外部删除后不复活且可存回原位置。
- 浏览器假数据下看过深浅两种模式。

## 没测到的

- **iCloud 冲突版本**：需要两台设备同时改同一个文件才能产生，代码路径（`NSFileVersion` 读取、合并、标记已解决）没有真机验证过。
- **移到废纸篓**：自测不碰真实的废纸篓，需要手动点一次。
- **原生右键菜单、行内重命名的手感、红绿灯位置**：截图要「屏幕录制」权限，没有截原生窗口；需要你实际看一眼，红绿灯不居中的话调 `lib.rs` 里的 `traffic_light_position`。
