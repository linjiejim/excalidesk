# iOS 预览 App：原生手势、和桌面端一样的渲染

- 日期：2026-11-22
- 状态：confirmed（Jim 2026-11-22：关掉 PR #4，从头做一个 Expo 的 iOS 预览 App，只看不改、不读在线链接，轻量、交互打磨好）。已在 iPhone 17 Pro 模拟器（iOS 26.5）本地验证，还没合并、没上真机
- 依赖：Expo SDK 58（React Native 0.88、expo-router 原生 Tab）、`@excalidraw/excalidraw` 0.18.1（仓库根目录那份）
- 范围：`mobile/`（App 和原生模块）、`src/shell/slideOrder.ts`（从 `slides.ts` 抽出的纯函数，桌面端行为不变）
- 不碰：桌面端功能、`.excalidraw` 格式、协作 / 分享链接（PR #4 那套，已关闭）

## 决策

- **D1 渲染：真 Excalidraw → 矢量 PDF → PDFKit。** 不自己写渲染器（PR #4 的 Canvas 版画不出手绘线条、Excalifont 和曲线箭头）。看不见的 WKWebView 里用和桌面端同一版本的 `exportToSvg` 导出，`WKWebView.createPDF` 拿到矢量 PDF，交给 `PDFView`。缩放、滚动、回弹、多页翻页都是系统原生的，放到很大也清楚。
- **D2 完全离线**：渲染页、JS 分块、Excalidraw 字体都打进 App（resource bundle），用 `WKURLSchemeHandler` 的自定义协议提供。字体约 13 MB，大头是中文手写体 Xiaolai。不用的话中文会退回系统字体，和桌面端不一样。
- **D3 缓存**：按「位置 + 路径 + 修改时间 + 大小 + 渲染版本」缓存 PDF、缩略图和摘要，每张图只渲染一次。打开的图优先，缩略图和搜索索引在后台排队。
- **D4 深色画布**：把 Excalidraw 深色滤镜（invert 93% + hue-rotate 180°）换算到每个颜色上，图片不反色。不用 CSS 滤镜，因为它在 PDF 里会变成位图。
- **D5 文件访问**：用户选文件夹，存成安全作用域书签，不要 iCloud 容器权限，模拟器和免费签名都能跑。iCloud 上没下载的文件不自动下载，打开时才下（协调读取）。「文件」App 里「用 Excalidesk 打开」也是原地打开，按单个文件记下来。
- **D6 界面**：Expo Router 原生 Tab（最近 / 文件夹 / 搜索，iOS 26 上是 Liquid Glass，搜索是单独的圆形按钮）、原生大标题、原生 `Stack.Toolbar` 按钮和菜单、`Link` 的缩放转场和长按预览 / 菜单。强调色用 Excalidraw 紫。
- **D7 幻灯片**：页 = frame（备注 frame 除外），顺序和备注配对用桌面端同一份 `slideOrder.ts`。按页查看时每个 frame 单独导出一页、不画 frame 边框；整张画布保留边框。
- **D8 批注**：Agent 的批注便签不进预览，和桌面端导出 PDF 一致。
