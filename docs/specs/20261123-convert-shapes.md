# 转换形状：文本、矩形、菱形、椭圆互转

- 日期：2026-11-23
- 状态：done（2026-11-23 实现完，PR 待合并；见「落地记录」）。确认时：Jim 2026-11-23 在会话里确认：不升级上游，自己做一层、交互对齐上游 master；Actions 栏按钮 + 浮层；Tab / ⇧Tab 循环；⇧R ⇧D ⇧O ⇧T 直接转换；文本转形状保留原对齐方式；文字放不下撑高容器、不缩字号；不进原生菜单；走 /yolo 交付
- 依赖：`@excalidraw/excalidraw` 0.18.1
- 范围：前端：转换逻辑、浮层、Actions 栏按钮、快捷键、文案、selftest
- 不碰：`.excalidraw` 文件格式、原生菜单、MCP、保存链路、Excalidraw 版本

## 背景

选中一个东西后想换个形状：一段文字想加个框，矩形想换成菱形。Excalidraw 0.18.1 没有这个功能，只有右键菜单里的「将文本包围在容器中」，而且会把文字强制改成居中。

上游 master 做了形状互转（`ConvertElementTypePopup`），但还没发版，npm 上只有 `0.18.0-<sha>` 快照。它只管矩形 / 菱形 / 椭圆互转和线 / 箭头互转，不管文本；入口只有 Tab 键浮层。换成快照要连带迁移导出、镜头、箭头绑定格式等一堆破坏性改动（见 D1），所以这里在 0.18.1 的公开 API 上做一层，交互和上游一致，等上游正式发版再把重复的部分删掉。

## 设计

### 能转什么

| 选中 | 可以转成 | 做法 |
|---|---|---|
| 独立的文本 | 矩形、菱形、椭圆 | 按文字大小生成容器，把文字绑进去 |
| 带文字的矩形 / 菱形 / 椭圆 | 文本 | 去掉容器，文字留在原位 |
| 矩形 / 菱形 / 椭圆 | 互相转换 | 换类型，其余不变 |

- 选中的每个元素单独转换；形状里的文字跟着形状走。转不了的（箭头、线、frame、图片、手绘线、嵌入、批注便签）跳过。全都转不了时，按钮不出现，快捷键不响应。
- 没有文字的形状不能转成文本：浮层里「文本」是灰的，⇧T 跳过它。
- 已经是目标类型的元素不动。

### 细节

- **文本 → 形状**
  - 容器尺寸和 Excalidraw 自己一样算（`computeContainerDimensionForBoundText`：四周留 5px，椭圆和菱形按内接区域放大），中心和文字中心重合；旋转角度、分组、所在 frame 跟文字一样。
  - 文字保留 id、字号、字体、颜色和**左中右对齐**，垂直居中。
  - 链接从文字挪到容器上（绑进容器的文字点不到）。连着文字的箭头改连容器。容器在图层里紧挨在文字下面。
- **形状 → 文本**
  - 文字回到没换行的原文，按对齐方式保持位置不动：左对齐保持左边，居中保持中线，右对齐保持右边；顶边不动。
  - 容器删掉；它的链接挪到文字上；连着容器的箭头改连文字。
- **形状互转**
  - 保留 id、位置、宽高、样式、旋转、分组、frame、链接、customData。
  - 圆角：矩形用 adaptive，菱形用 proportional；没有圆角的保持没有。
  - 里面的文字按新形状重新排；放不下就把容器撑高，字号不变。
- **箭头**：连着被转换元素的箭头，绑定保持不变，端点沿最后一段的方向挪到新轮廓上（保留原来的 gap）。沿这个方向碰不到新轮廓时，改为朝中心方向。

### 入口

1. **Actions 栏按钮**：选中可转换的元素时，属性面板 Actions 栏末尾多一个「转换形状」按钮。点开在属性面板右边、和按钮同一高度弹出浮层（Actions 那一排会换行，按钮不一定在最右边），四个选项：矩形、菱形、椭圆、文本，当前类型高亮。点一项即转换并收起。
2. **Tab / ⇧Tab**（和上游一致）：第一次按 Tab 在选区左下方弹出同一个浮层，不改图；再按 Tab 换到下一种、⇧Tab 换到上一种，边换边看到效果；回车、Esc、点别处、选择变了、按了其他键都收起，保留当前结果。顺序：矩形 → 菱形 → 椭圆 → 文本，跳过不可用的项。
3. **⇧R / ⇧D / ⇧O / ⇧T**：直接转成矩形 / 菱形 / 椭圆 / 文本。

快捷键只在画布上生效：正在编辑文字、焦点在输入框里、输入法正在组字、放映中都不响应；带 ⌘ / ⌃ / ⌥ 时也不响应。按物理键位（`e.code`）判断。浮层上每一项的提示带快捷键，比如「矩形 ⇧R」。

### 撤销

- 点按钮选项和 ⇧ 快捷键：一次转换一步撤销。
- 一整轮 Tab 只算一步撤销。Excalidraw 0.18.1 的 `updateScene` 在调用时同步记撤销，并且会过滤掉还没记录的本地改动，所以「先用 EVENTUALLY 改、最后补一次 IMMEDIATELY」记不下来。做法：循环中每一步都从这轮开始前的原样算出结果，用 `NEVER` 写进去（不进撤销记录）；收起时先把元素恢复成原样（`NEVER`），再一次性写入最终结果（`IMMEDIATELY`）。最终结果和原样相同就只恢复，不记撤销。

### 和上游的接缝

升级到自带转换浮层的 Excalidraw 时：

- 形状互转和 Tab 交给上游，删掉 `convert.ts` 里形状互转的部分和 Tab 处理；文本 ↔ 形状、Actions 按钮和 ⇧ 快捷键保留，改成调上游的转换。
- 重新核对 ⇧R ⇧D ⇧O ⇧T 有没有被上游占用：上游已经开始给工具分配 Shift+字母（⇧X），我们的处理先于 Excalidraw 拿到按键，撞了会把上游的功能悄悄盖掉。
- Actions 栏按钮是 DOM 注入的，确认它还能插进去（selftest 有这一步）。

## 验收

1. 选中一段左对齐的多行文本按 ⇧R：变成矩形，文字在里面，仍然左对齐、字号不变、没有多出换行，文字 id 不变；⌘Z 一步回到原样。
2. 同样的文本按 ⇧D / ⇧O：得到菱形 / 椭圆，文字完整地在形状里面。
3. 带文字的矩形按 ⇧D：同一个 id，x、y、宽度不变，类型变成菱形；文字放不下时容器变高，字号不变。
4. 带文字的形状按 ⇧T：容器没了，文字在原位，内容是没换行的原文。没有文字的形状按 ⇧T 没有变化，浮层里「文本」是灰的。
5. 箭头连着矩形，矩形转成椭圆后：箭头的绑定还指向同一个 id，端点到椭圆轮廓的距离不超过 gap + 2px。文本转成形状后，原来连着文本的箭头改连容器。
6. Tab 弹出浮层、不改图；再按 Tab 变成下一种，⇧Tab 变回上一种；Esc 收起后保留结果；整轮只占一步撤销：⌘Z 一次回到按 Tab 之前。
7. 选中可转换的元素时，Actions 栏有「转换形状」按钮，点开选一项即转换；只选中箭头时没有这个按钮，Tab 和 ⇧R 也不改图。
8. 正在编辑文字时按 Tab、⇧R，是正常输入，不触发转换。
9. 多选一段文本和一个矩形按 ⇧O：两个都变成椭圆。
10. `npm run typecheck`、`npm run build`、`bench/selftest.sh`（含新步骤）全过。

## 不做

- 线 ↔ 箭头（含直角 / 曲线 / 折线）互转。留到 V2，⇧A、⇧L 先空着。
- frame、图片、手绘线、嵌入、批注便签等其他类型。
- 原生菜单项（原生菜单会先吃掉按键，在文本框里打大写 R 也会触发）和 Excalidraw 右键菜单项（0.18.1 不开放）。
- Excalidraw 帮助面板（`?`）里的条目（0.18.1 不开放）。
- MCP / Agent 的转换工具。
- 升级 Excalidraw。

## 决策

- **D1 不升级上游，在 0.18.1 上自己做一层，交互对齐上游 master。** Jim 定的。上游未发版；换成 master 快照要迁移：导出 API（`exportToBlob` / `exportToSvg` / `exportToCanvas` → `exportScene`，影响 PNG/SVG、PDF、MCP 渲染、iOS 预览）、`scrollToContent` → `setViewport`、`excalidrawAPI` 改名、箭头绑定从 `{focus, gap}` 换成 `{fixedPoint, mode}`（文件格式随之变化）、`convertToExcalidrawElements` 摆箭头的方式。而且上游也不管文本。不选：跟 master 快照（依赖会随时变）；等 0.19（没有日期）。
- **D2 文本转形状保留原来的对齐方式。** Jim 定的。Excalidraw 自带的「将文本包围在容器中」强制居中，左对齐的列表会乱。
- **D3 文字放不下时撑高容器，不缩字号。** Jim 定的。和 Excalidraw 打字时的行为一致；上游是缩字号。
- **D4 快捷键用 ⇧ + 工具字母，不用 ⌘ / ⌥。** Jim 定的。R/D/O/T 本来就是这几个工具的键；⇧+字母在 0.18.1、上游 master、Excalidesk 菜单里都没被占用（上游 master 的 Shift 工具键只有 ⇧X）。⌘D 是复制、⌘O 是打开、⌘R 是刷新习惯、⌘T 是新标签习惯、⌘⇧R 是「在 Finder 中显示」；⌥R 是只读模式，⌥+字母在 Mac 上还会打出特殊字符。
- **D5 不进原生菜单。** Jim 定的。理由见「不做」。
- **D6 Actions 栏按钮靠 DOM 注入。** 0.18.1 的 Actions 栏是写死的，没有扩展口。用 MutationObserver 找到 Actions 那一组按钮，往末尾插一个槽，用 React portal 渲染按钮。不选：patch-package 改 dist（dev 和压缩过的 prod 两份都要改，升级更难）。
- **D7 一整轮 Tab 一步撤销的做法见「撤销」。** 实现前查 0.18.1 的 Store 定下的。
- **D8（实现中补充）文本转形状时重新量一次文字宽度。** 场景里存的宽度可能是字体加载完之前量的（偏窄），按它建容器会多出换行。自动宽度的文字取存的宽度和重新量的宽度里大的那个，按对齐方式保持左边 / 中线 / 右边不动；固定宽度（`autoResize: false`）的文字按它存的宽度换行。
- **D9（实现中补充）新容器的样式：描边颜色和透明度跟文字，其余用当前画笔。** 填充、线宽、线型、粗糙度、圆角和 Excalidraw 的「将文本包围在容器中」一样取当前画笔；描边用文字的颜色，框和字是一个颜色。
- **D10（实现中补充）Tab 只在焦点在画布上时拦。** 和上游一样：焦点在属性面板的按钮上时，Tab 照常移动焦点。只读模式下快捷键和按钮都不响应。
- **D11（实现中补充）批注跟着走。** 形状转成文本时容器被删，指着容器的批注改指文字；其他情况 id 不变，批注不用动。
- **D12（实现中补充）退出放映后放回选择，改成在 Excalidraw 提交「退出只读」的那次 onChange 里做。** selftest 里「退出后原样恢复」在这个分支上时过时不过：原来退出放映后等一帧（rAF）再放回选择，但退出全屏的过渡里 WKWebView 可能好几帧不出画面，等不到；React 还没提交时放回去，又会和退出只读合进同一次渲染、被 Excalidraw 的 `deselectElements()` 清掉。main 上也是同一个竞态，只是这个分支每次渲染多了点工作，更容易输。Excalidraw 在 `componentDidUpdate` 里先排队清空选择、再调 `onChange`，在这次 onChange 里放回去正好排在清空后面，不靠帧。

- **D13（审查后补充）浮层开着时别人改了这一轮的元素，这一轮作废。** 每一步和收起都从开始前的快照算，Agent、外部修改、iCloud 合并、恢复历史版本在这期间改了同一批元素（单元、里面的文字、连着的箭头），收起时会被盖回去。现在每次写完记下这些元素（含指着它们的批注）的版本号和 nonce（合并时版本相同按 nonce 定胜负，只比版本号会漏掉），onChange、下一步、收起时对不上就作废这一轮：场景保持现在的样子，别人的修改胜出，循环中的中间状态不进撤销记录。
- **D14（审查后补充）选择的规则。** 一起选中、但转换不了的元素（箭头、图片……）转换后照样选着。收起时如果选择已经不是我们设的那套（用户点了别处、新建一页、开始放映），就只写元素，不把选择改回去。用 Actions 按钮再点一下收起时，和 Esc 一样保留当前结果；Tab 浮层开着时点按钮，先收起 Tab 这一轮再打开按钮的浮层。
- **D15（审查后补充）撤销转换不留下指着文字的已删除容器。** 新建的容器如果撤销后变成「已删除、但 boundElements 里还登记着文字」，存进文件后，下次打开（或 Agent 改图、合并）时 `restoreElements({ repairBindings })` 不跳过已删除的容器，会把活着的文字绑回去，文字就再也点不中。会出问题的是 Tab 循环：收起时先把元素恢复成原样，新容器被标成删除，原来还留着链接，最终结果是从这个状态记的撤销。现在恢复原样时去掉链接（`unlinked`）。直接转换（容器在快照里不存在）时，Excalidraw 0.18.1 的撤销本来就会清掉 boundElements（实测它自带的「将文本包围在容器中」+ ⌘Z 也是这样）；收起时新容器还是先以「已删除、不连任何东西」写进场景再写最终结果，让这条路径不依赖 Excalidraw 撤销的这个细节。
