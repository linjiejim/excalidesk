# 批注：收起成小圆点、选中批注按 C 改它

- 日期：2026-11-24
- 状态：done（2026-11-24 实现，#9 合并，0.9.0 发布；Jim 在会话里确认提交、合并、发布）
- 依赖：`@excalidraw/excalidraw` 0.18.1
- 范围：前端（收起的显示形态、小圆点、开关、编辑批注）、MCP `get_feedback` 多一个 `edited`、selftest
- 不碰：`.excalidraw` 文件格式、批注的数据结构（只多一个可选的 `comment.editedAt`）、保存链路的协议、iOS 预览

## 背景

批注是画布上真实的元素（黄色便签 + 里面的文字 + 指向目标的虚线箭头，`customData.excalidesk.comment / commentOf`）。批注一多，画面就乱。另外，选中一条批注再按 C，会在画布中间再开一条新批注，而不是改这一条。

## 设计

### 收起批注

- **开关**：⇧C（和 Figma 一样；Excalidraw 只在配合 ⌘⌥ / ⌥⇧ 时用 C）、底部 Agent 栏的「收起 / 展开」、主菜单「收起批注 / 展开批注」。所有标签共用一个开关，记在 localStorage，重启后保留。
- **收起后**：便签、文字、箭头都从画布上消失，每条批注只留一个小圆点：有箭头的在箭头指着的那一头（目标元素旁边，原来箭头头上那个圆点的位置），没有箭头的在便签左上角。橙色 = 未处理，灰色小一点 = 已处理。
  - 悬停小圆点：浮出批注原文（不含 Agent 的回复）。
  - 点小圆点：打开这条批注的输入框（见下一节），可以直接改。
  - 「N 条批注」（下一条）：收起时滚到那条批注并打开它的输入框；展开时和以前一样选中它。
  - 收起时按 C 新建的批注，保存后直接是小圆点。
- **只改画布上的样子，不写文件**：收起时把画布里的批注元素换成「显示形态」：`opacity: 0`、`locked: true`，原来的 opacity / locked 记在 `customData.excalidesk.folded`。**版本号和 nonce 都不变**，所以：
  - Excalidraw 不记撤销（它的快照按 `versionNonce` 判断变化），⌘Z 撤的还是上一次真正的修改；
  - DocSession 不算改动、不标脏、不写盘；
  - 锁住 = 点不中、框选和全选都不会带上它、橡皮擦不会擦到它。收起的那一刻如果正选着批注，会取消选中（锁住的东西选着还能被删、被挪）。
- **还原的地方都在 DocSession**（`session.ts`），一个口子进、一个口子出：
  - 出：`current()`（Agent 的读写、合并外部修改、iCloud 冲突、历史恢复、撤销 Agent、另存为都从这里读）和 `doSave()` 发出去的元素，一律还原成原样。Rust、MCP、iOS 预览、别的 Excalidraw 看到的永远是原样。
  - 进：`apply()`、`initialData()` 按开关换成显示形态。
  - 兜底：`onChange` 里版本号变了（撤销重做、转换形状收起、别处换了整个场景）就检查一遍，样子不对就在微任务里改回来（画面刷新前，不会闪）。读文件时也还原一遍，万一哪条路漏了，下次打开就自愈。
- **撤销重做**：Excalidraw 的撤销只换改过的那几个字段，展开时记下的一步拿到收起的批注上撤销（或者反过来），会把显示形态和原样拼在一起：比如换回一份没有记号的 customData，opacity 却还是 0。两层保证：
  - 撤销记录里只有原样：收起时 `apply()` 先以原样提交（`updateScene` 当场把这一步记进撤销快照），再换成显示形态（NEVER、nonce 不变，快照不跟着换）。两步之间不渲染，不会闪。
  - 原样按 `realOf` 算：展开时没记号的元素，上面的值就是原样（用户自己锁住、调透明都照存）。收起时（或有记号时）不是隐藏值的（opacity ≠ 0、locked ≠ true）就是原样（撤销刚换回来的）；是隐藏值才看记号；记号也被换掉了，就看 DocSession 记着的上次算出的原样。
  - 撤销重做拼出来的元素（有记号却不是隐藏值，或收起时没记号却锁着 / 透明）：Excalidraw 会把撤销结果存进撤销快照，所以 `applyNoteView` 先抬版本、以原样写一次（NEVER：不进撤销，快照换成原样），再收起。代价是这种撤销之后多存一次盘。
- **藏着的批注碰不到**：锁住的元素 Excalidraw 0.18.1 自己就跳过：点不中、框选不到、橡皮擦不擦，找「往哪个容器里写字」时也跳过（`isTextBindableContainer(el, false)`），在藏着的便签上双击或拿文字工具点一下，是在那里新建文字。

### 选中批注按 C = 改它

- 选中的正好是一条批注（便签、里面的文字、箭头，或者整组）时，C 打开输入框，里面是原文（Agent 的回复不算），光标在末尾。展开时输入框盖在便签上，收起时贴着小圆点。底部提示「编辑批注」。
- 选中批注 + 别的元素、或者选了几条批注：和以前一样，给其中不是批注的元素新建批注。
- 保存：便签按新文字重新排版（高度跟着文字，不小于新建时的 56），记 `comment.editedAt`，作为一次可撤销的修改。文字没变就什么都不做。
- **已处理的批注改了文字 = 重新打开**：状态改回 `open`，去掉 `reply / resolvedBy / resolvedAt` 和文字里的回复，恢复黄色便签、深色文字、橙色箭头。输入框提示「已处理，保存后重新打开」。
- 输入框现在钉在画布坐标上，平移、缩放时跟着走（以前是固定在屏幕上的）。

### MCP

- `get_feedback` 的每条批注多一个 `edited`：Agent 上次看过之后，用户改过这条批注的文字（含改了已处理的批注、让它重新打开）。基线（`mcp/baselines/*.json`）多存一份批注原文 `comment_text`；旧版存下的基线没有这一项，照样能读，只是不标 `edited`。

## 决策

- **D1 收起只在画布上，不写进文件**。另一种做法是把「收起」存进每条批注（缩成小方块、文字透明），但那样会改文件、进撤销、触发 iCloud 同步，老版本和别的 Excalidraw 打开会看到一堆透明的东西，Agent 渲染出来的图也看不到批注。看不看批注是看的人自己的偏好，和 Figma 的 ⇧C 一样。
- **D2 用 opacity + locked 藏，而不是 isDeleted**。isDeleted 一样碰不到，但撤销「新建批注」后再还原时分不清「藏着」和「真删了」，会把删掉的批注复活。锁住的元素 Excalidraw 的点击、框选、写字、橡皮擦都会跳过，不用另外拦。
- **D3 一个开关管所有标签**，不按文件分开记：要的是「现在别让批注挡着」，切到别的图也一样。
- **D4 改已处理的批注会重新打开它**：改了文字就是有新要求，留着「已处理」Agent 就看不到（`get_feedback` 只列未处理的）。只看不改（文字没变）不会重新打开。

## 已知限制

- 收起时批注都是锁住的，所以画布右键菜单会出现「全部解锁」。点了会把所有批注抬一次版本（多一步撤销、存一次盘，内容不变），它们马上又被收起；用户自己锁住的批注会变成没锁（就是「全部解锁」的意思）。0.18.1 的右键菜单不能定制，先不处理。
- 看得见的形状和藏着的便签叠在一起时，拿文字工具点那里、或者什么都没选时双击：Excalidraw 找容器时最上面命中的是那条锁住的便签，于是新建一段文字，而不是改形状的标签。和 Excalidraw 里任何锁住的元素盖在形状上一样。正常双击（第一下会选中那个形状）不受影响。

- 展开时只改了批注的锁或透明度（没改别的），收起后 ⌘Z 再 ⇧⌘Z：重做那一步只带锁 / 透明度，落在显示形态上看不出差别，所以重做丢掉了这次改动（文件里还是撤销后的样子）。要修得改 Excalidraw 的重做栈，先不处理。

## 验收

- selftest 新增 13 步（`批注：…`）：新建后文件是原样；⇧C 收起后画布透明锁住、取消选中、有小圆点、不写盘、不进撤销（⌘Z 撤的是新建、重做回来照样收着）；收起时别的修改照常保存、全量保存里批注也是原样、外部修改载入后仍收着；收起时 Agent 处理批注，文件里是灰色已处理、画布上还收着；藏着的便签上双击、拿文字工具点，Excalidraw 新建文字、不碰批注；点小圆点改文字让已处理的重新打开、⌘Z 一步撤销；⇧C 展开回到原样、不写盘；展开时选中批注按 C 是改它、不会多一条；展开时改的、收起后 ⌘Z / ⇧⌘Z，文件里批注不透明、没锁、没记号；展开时 Agent 处理、收起后 ⌘Z，回到未处理且是原样；展开时用户自己锁住的批注存盘是锁住的，收起再展开还锁着；收起时撤销、展开后再撤销，不会冒出锁住 / 透明；删掉的锁住批注收起后不会一直存盘。
- `cargo test`：`feedback_marks_edited_comments`（改过标 `edited`；没改不标；旧格式基线能读）。
