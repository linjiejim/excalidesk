# v0.3.0：打磨

2026-11-06

## 改了什么

| 项 | 说明 |
|---|---|
| 整页不再滚动 | 原因：欢迎页和「正在打开」占位用了 `height: 100%` 再加 padding，比窗口高，整页被撑出滚动条。全局改成 `box-sizing: border-box`，`html/body` 禁止滚动，只有侧边栏列表、历史列表在各自区域内滚 |
| 打开慢时的提示 | 打开超过 6 秒显示「可能在等 iCloud 下载」并给「关闭标签」按钮；iCloud 文件打开前先查同步状态，没下载的直接显示「正在从 iCloud 下载」 |
| 左上角 logo | 侧边栏顶部（红绿灯右边）放矢量版 logo + 名字，纸面、紫色圆、铅笔三部分都跟着主题变色；侧边栏收起时 logo 移到标签栏 |
| 设置（⌘,） | 外观：跟随系统 / 浅色 / 深色；语言：跟随系统 / 简体中文 / English；侧边栏排序。窗口外观（红绿灯、系统对话框）跟着切换 |
| 中英双语 | 外壳所有文案、原生菜单（切换语言时重建）、右键菜单、对话框按钮、Rust 返回的错误（改成 `err.xxx` 键，由前端翻译）、Excalidraw 自己的界面（`langCode`） |
| 应用本地化声明 | Info.plist 声明 en / zh-Hans。否则 WKWebView 的 `navigator.language` 永远是英文，「跟随系统」形同虚设；系统文件对话框也会跟着用中文 |
| 最近打开 | 移到废纸篓后从最近打开里拿掉；启动时清掉已经不存在的文件；「其他最近打开」里的文件右键可「从最近打开中移除」 |
| 双击改名 | 侧边栏文件和文件夹双击进入行内重命名 |
| 拖动工作区 | 按住工作区那一行上下拖，显示插入位置，顺序存进状态文件 |
| 排序 | 修改时间（最新在上，默认）/ 创建时间 / 名称；文件夹在前，文件夹的时间取里面最新的那张图；名称用 `Intl.Collator`（数字按大小） |

## 注意

这台 Mac 的系统语言首选是英文（`en-CN`，其次 `zh-Hans-CN`），所以「跟随系统」显示英文；在设置里选「简体中文」即可，会记住。

## 验证

- 端到端自测 22 步全部通过。新增：拖动调整工作区顺序并持久化、排序规则、中英切换、最近打开自动清理不存在的文件。
- 浏览器假数据下看过：浅色英文、深色中文、设置弹窗、整页滚动（`scrollHeight == clientHeight`）。
